Architecture

From socket to response in five steps.

  • Listener
  • Parser
  • Dispatcher
  • Handler
  • Response writer
  1. The listener accepts a TCP (or TLS) connection and starts a goroutine for it.
  2. The parser reads the request line, headers and body, rejecting malformed or oversized requests.
  3. The dispatcher walks the configured routes in order and picks the first handler that matches.
  4. The handler serves a file, proxies to a backend or renders the status page.
  5. The response writer sends the bytes, then either waits for the next request or closes.
