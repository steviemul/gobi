gobi

A small HTTP/1.1 web server written in Go, built from the TCP socket up.

gobi doesn’t use net/http. It accepts raw connections, parses requests, builds responses and manages connection lifetime itself. You are reading this page through it: the HTML, the stylesheet, the script, the images and the JSON data were each served by a separate request.

Static files

Routes with a root serve files from a directory, with the right content type.

Virtual hosts

Routes can match on the Host header, so one server can host several sites.

TLS

HTTPS with locally trusted mkcert certificates, and an optional redirect from HTTP.
